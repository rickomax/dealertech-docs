# `ui_element:set_visible(visible)`

Shows or hides this element and its children. A hidden element is removed from layout and stops receiving input until shown again; unlike `destroy` this is reversible.

**Parameters**
- `visible` (`boolean`) — `true` to show the element, `false` to hide it.
